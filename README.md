# CodeTime Plugin

CodeTime 查询与绑定插件，所有命令使用 `#ct` 前缀。

## 结构

- `apps/bind/`：账号绑定管理
- `apps/query/`：查询类命令
- `model/`：API、格式化、时间范围、账号存储等公共能力

## 命令

### 绑定

- `#ct绑定 [cookie]`
- `#ct绑定列表`
- `#ct账号列表`
- `#ct切换绑定 [序号]`
- `#ct切换账号 [序号]`
- `#ct删除绑定 [序号]`
- `#ct删除账号 [序号]`

### 查询

- `#ct今日`
- `#ct(我的)?资料`
- `#ct(近期|最近)?日志 <个数>`
- `#ct(编程)?(日|周|月|年)时间`
- `#ct(编程)?(日|周|月|年)详情 <语言|项目>`
- `#ct(编程)?(日|周|月|年)时间分布`
- `#ct(编程)?排行 <语言|项目|平台>`

绑定信息存储在 Redis：`CODETIME:USER:{QQ}`
